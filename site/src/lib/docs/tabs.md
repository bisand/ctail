Every open file lives in its own tab in the bar at the top of the window.

## Switching

- Click a tab.
- <kbd>⌃Tab</kbd> moves to the next tab, <kbd>⌃⇧Tab</kbd> to the previous one.
- A quick <kbd>⌃Tab</kbd> tap toggles between the two most recently used tabs, like Alt-Tab.

## Organising

- **Reorder** by dragging a tab left or right.
- **Rename** by double-clicking a tab or choosing **Rename…** from its context menu. The custom label replaces the file name in the tab and status bar; the file itself is untouched.
- **Colour** a tab from the context menu's **Color** submenu. Six colours are available, plus **No Color**. Colours are handy for telling staging from production.

## Closing and reopening

- <kbd>⌘W</kbd> or the × button closes the active tab.
- <kbd>⌘⇧T</kbd> reopens the last closed tab, in the same way a browser does.
- Closing the last tab quits the app.

## Context menu

Right-click a tab for:

| Item | What it does |
|---|---|
| Rename… | Give the tab a custom label |
| Color ▸ | Assign one of six colours, or none |
| Refresh | Reload the file from disk |
| Change File Path… | Point this tab at a different file, keeping its label and colour |
| Copy Path | Copy the full path to the clipboard |
| Reveal in Finder | Show the file in Finder |
| Close Tab | Close it |

## Activity and warnings

- Inactive tabs show a small badge when new lines arrive, so you can watch several files without switching.
- A warning marker appears on a tab whose file is unreachable, for instance when a network share drops. It clears when the file is back.

## Session restore

Open tabs, their order, labels, colours and the active tab are saved every time they change. On the next launch ctail reopens them, even after a crash or force quit. Turn this off with **Restore tabs on launch** in [Settings](../settings/).

New tabs open at the end of the bar by default. The **New tab position** setting can place them next to the current tab instead.
