| Shortcut | Action |
|---|---|
| <kbd>⌘O</kbd> | Open file(s) |
| <kbd>⌘W</kbd> | Close current tab |
| <kbd>⌘⇧T</kbd> | Reopen last closed tab |
| <kbd>⌃Tab</kbd> | Next tab, or toggle between the last two tabs when tapped quickly |
| <kbd>⌃⇧Tab</kbd> | Previous tab |
| <kbd>⌘F</kbd> | Find |
| <kbd>Enter</kbd> | Next match (search bar open) |
| <kbd>⇧Enter</kbd> | Previous match (search bar open) |
| <kbd>Esc</kbd> | Close search |
| <kbd>⌘C</kbd> | Copy selection |
| <kbd>⌘A</kbd> | Select all |
| <kbd>⌘⇧L</kbd> | Toggle line numbers |
| <kbd>⌘⌥W</kbd> | Toggle word wrap |
| <kbd>⌘,</kbd> | Settings |
| <kbd>⌘⇧A</kbd> | AI assistant |
| <kbd>⌘Q</kbd> | Quit |

Selection in the log view follows macOS conventions: click selects a line, <kbd>⇧</kbd>-click extends the selection, <kbd>⌘</kbd>-click toggles individual lines and click-drag selects a range.
