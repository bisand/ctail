## Tab context menu

Right-click any tab:

| Item | Description |
|---|---|
| Rename… | Custom label for the tab |
| Color ▸ | Six colours or No Color |
| Refresh | Reload the file from disk |
| Change File Path… | Point the tab at another file |
| Copy Path | Copy the full path |
| Reveal in Finder | Show the file in Finder |
| Close Tab | Close the tab |

## Log context menu

Right-click in the log view:

| Item | Description |
|---|---|
| Copy | Copy the selected lines |
| Select All | Select every loaded line |
| Ask AI about logs | Open the AI assistant with the current tab's context |

## Dock

Drag files onto the Dock icon to open them. The Dock menu also lists recent files.
